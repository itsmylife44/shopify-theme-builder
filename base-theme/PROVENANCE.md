# Provenance

This folder is Shopify's Skeleton theme, vendored as the Base Theme (see `docs/adr/0002-skeleton-as-base-theme.md`). The files here are covered by Shopify's license in `LICENSE.md`, not by the repo's MIT license.

- Source: https://github.com/Shopify/skeleton-theme
- Version: `main` at commit `a4f32d393b9eadf6c4403318ca39116832e5d1df` (2026-02-26), after tag `v1.0.0`
- Vendored on 2026-09-22: the theme folders (`assets`, `blocks`, `config`, `layout`, `locales`, `sections`, `snippets`, `templates`), `.theme-check.yml`, `.shopifyignore` and `LICENSE.md`, unmodified. Left out: the repo's README, contributor docs and GitHub workflows.

Changes made to these files after vendoring are this repo's own and are listed in its Git history.
